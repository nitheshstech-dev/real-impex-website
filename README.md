# REAL IMPEX — Corporate Website

Official B2B website project for **REAL IMPEX**, a Karur, Tamil Nadu-based home textile manufacturing and export partner.

## Pages
- `index.html` — corporate homepage
- `products.html` — product portfolio
- `product-detail.html` — product category detail experience

## Built with
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive, accessibility-conscious UI
- SEO metadata and structured data

## Assets
Official REAL IMPEX branding, product imagery, company profile and statutory/certification documentation are stored under `assets/`.

## Content integrity
The website avoids unsupported claims. Certification details, customer names, market claims, registration numbers and similar business facts should only be published after verification against official records.
